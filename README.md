# Site Institucional Grupo Almeida

**Nome do projeto:** Site Institucional Grupo Almeida
**Objetivo do site:** Construir um novo site institucional para apresentar o Grupo Almeida de forma sólida, moderna e profissional. O site deve funcionar principalmente como cartão de visita institucional e instrumento de reputação.
**Cliente:** Grupo Almeida
**Responsável pelo desenvolvimento:** Sartec Digital
**Estado atual do projeto:** Fundação documental concluída localmente.

## ANTES DE TRABALHAR NESTE PROJETO

Leia nesta ordem:

1. `CONTEXTO_PROJETO_SITE.md`
2. `DECISOES.md`
3. o arquivo diretamente relacionado à tarefa

`AGENT_RULES_SITE.md` contém regras gerais leves e pode ser consultado quando necessário — não é leitura obrigatória para toda tarefa.

Não é preciso ler automaticamente `diario/HISTORICO.md`, `FECHAR_DIA.md` ou decisões arquivadas antes de uma tarefa comum.

## DOCUMENTOS VIVOS

- `CONTEXTO_PROJETO_SITE.md`: contexto permanente do projeto — o que é, para quem, e por quê.
- `DECISOES.md`: somente as decisões de produto, negócio e infraestrutura que ainda valem hoje.
- `AGENT_RULES_SITE.md`: regras gerais leves de como trabalhar aqui. Consulta eventual, não bootstrap obrigatório.
- `historico/DECISOES_ARQUIVADAS_ATE_2026-08-17.md`: histórico de decisões substituídas e tentativas de implementação anteriores. Consulta eventual, quando for necessário investigar a história de uma decisão antiga.
- `DEPOIS.md`: backlog e memória auxiliar, não fonte de verdade nem lista automática de tarefas.
- `ACESSOS.md`: controle de acessos necessários (sem senhas).
- `FECHAR_DIA.md`: procedimento opcional, usado somente quando o responsável pedir para fechar o dia.
- `diario/`: histórico de trabalho, não contexto obrigatório de desenvolvimento.
