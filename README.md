# Site Institucional Grupo Almeida

**Nome do projeto:** Site Institucional Grupo Almeida
**Objetivo do site:** Construir um novo site institucional para apresentar o Grupo Almeida de forma sólida, moderna e profissional. O site deve funcionar principalmente como cartão de visita institucional e instrumento de reputação.
**Cliente:** Grupo Almeida
**Responsável pelo desenvolvimento:** Sartec Digital
**Estado atual do projeto:** Fundação documental concluída localmente.

## ANTES DE TRABALHAR NESTE PROJETO

Leia nesta ordem:

1. `AGENT_RULES_SITE.md`
2. `CONTEXTO_PROJETO_SITE.md`
3. `DECISOES.md`
4. última entrada de `diario/HISTORICO.md`
5. arquivo específico relacionado à tarefa

Para encerrar uma jornada, seguir `FECHAR_DIA.md`.

## DOCUMENTOS VIVOS

- `CONTEXTO_PROJETO_SITE.md`: A fonte da verdade sobre o que é o projeto e por quê.
- `AGENT_RULES_SITE.md`: Define COMO qualquer agente de IA deve trabalhar neste projeto.
- `DECISOES.md`: Registro cronológico de decisões estruturais confirmadas e pendentes.
- `DEPOIS.md`: Estacionamento de ideias e itens fora da tarefa atual.
- `ACESSOS.md`: Controle de acessos necessários (sem senhas).
- `FECHAR_DIA.md`: Procedimento oficial para encerramento da jornada de trabalho. Levanta o que aconteceu no dia, cria/complementa o diário diário, atualiza o índice e propaga decisões, pendências e acessos aos arquivos corretos.
- `diario/HISTORICO.md`: Índice resumido dos dias trabalhados. Deve permitir localizar rapidamente a evolução do projeto sem carregar todos os detalhes.
- `diario/AAAA-MM-DD.md`: Registro detalhado de uma jornada específica: o que mudou, como foi feito, decisões, problemas, correções e pendências.
